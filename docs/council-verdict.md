# Council verdict

Date: 2026-11-20

Question: how should a team of coding agents become the foundation for later one-click applications?

## Chairman

Build the line first. Do not build highlight desk or close books in this repository.

The line is nine roles, four chains, a handoff file between roles, and a validator. Example briefs stay in `apps/` so a later chain can pick them up. Posting, paying, and filing stop at a human gate.

## What failed if we skipped this

A shared agent that also edits video and books becomes one crowded thread. It looks autonomous until the context fills and the next task contradicts the first.

## Next step

`node bin/devak.mjs session feature "<one change to the line>"` and let the chain run. Do not open an application brief in that session.
